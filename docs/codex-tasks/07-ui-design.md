# Air Health · 五页导航方案

## 布局

底部固定五个入口：今天、动作库、计划、饮食、我的。首屏回答“今天做什么”，以当前训练日名称、动作数和一个主按钮作为视觉重点。周一到周日的完成情况放在下一张卡片，完成与休息均有文字标记。

动作库主包页只提供部位网格和搜索入口，所有动作数据、详情和筛选逻辑留在分包。计划页保留现有管理与编辑能力，直接跳转全屏训练页。饮食沿用现有营养记录和识别流程，保留减脂入口。我的提供累计记录概览、历史日历、统计与个人纪录、体重管理入口，历史和统计保留独立详情页面。

## 视觉与交互

- 沿用雾白背景 `#F4F8F7`、白色卡片、深青正文；红色只用于主操作、当前选择和重点数字。
- 卡片统一 28rpx 圆角，弱边框，取消装饰性渐变和光晕；减少英文眉题与重复说明。
- 训练页使用 `#141A1D` 深色背景、`#202A2F` 卡片、白色正文，尚未完成的当前组高亮；休息计时固定在底部，输入区预留安全距离。
- 正文保持可读，操作区至少 88rpx 高；数字用等宽数字；长动作名称允许换行。
- 部位使用动作库既定十色色板，不引入数据集图片或新 npm 依赖，Tab 复用现有 PNG。

## 兼容与验证

不迁移存储、不更换 key。今天的建议日从当前启用计划与已有训练记录推导，允许用户手动切换。训练页面通过 navigateTo 打开，保存后返回今天可看到更新。

每完成一个页面运行全部 Node 测试；额外验证 Tab 配置与组件一致、所有导航目标存在、主包无同步分包依赖、分包文本体积和上传忽略项。实际微信渲染、系统返回、输入键盘、后台计时与设备振动在开发者工具/真机验收。
