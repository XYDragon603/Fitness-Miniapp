## 新的信息架构（5 个 tab）
| Tab | 内容 | 来源 |
|---|---|---|
| 今天 | 今天练什么：大卡片 + “开始训练”；本周完成情况；休息日显示恢复建议 | 由 index 和 record 的入口合并 |
| 动作库 | 动作库列表 | **注意：tabBar 页面必须在主包里**。方案：主包新建一个轻量的 `pages/library/library` 作为入口（部位网格 + 搜索框），点击后进入分包列表页 |
| 计划 | 计划管理和编辑 | 现在的 index |
| 饮食 | 营养记录、拍照识别、减脂参考 | nutrition + fatloss |
| 我的 | 历史日历、统计、个人纪录、体重 | history + stats |

- 训练中（record）不再是 tab，改为从“今天”进入的全屏页面，这个页面使用深色样式（训练时更专注）。
- `custom-tab-bar` 和 `app.json` 的 tabBar 要同步修改。tab 图标需要新的 5 组 png（81×81，未选中和选中各一张），可以先复用旧图标。

## 视觉
- 沿用 `docs/superpowers/specs/` 里的 Air Health 方向和 `app.wxss` 的 `--air-*` 变量，在此基础上收敛：
  - 一个主色（红）只用于主按钮和关键数字；部位用固定的 10 色色板（和 03 列表页的色块保持一致）
  - 减少渐变、光晕和小字说明文案；每个卡片只回答一个问题
  - 数字使用等宽数字（`font-variant-numeric: tabular-nums`）
- 训练中页面：深色背景，当前组高亮，休息计时条和加量建议放在显眼的位置。
