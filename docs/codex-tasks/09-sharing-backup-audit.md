## 部署恢复后如何继续

1. 微信开发者工具 → 云开发，选中上述环境。
2. 云函数现已部署，后续更新优先使用下面的显式 AppID 脚本；避免继续使用已确认触发签名问题的旧 CLI 参数组合。
3. 或运行 `powershell -ExecutionPolicy Bypass -File tools/deploy-user-backup.ps1`，脚本只部署 `userBackup`，不修改 `foodRecognize`。
4. 当前代码兼容云端 Node.js 16.13；建议在云开发 → 云函数 → userBackup → 配置中将超时调到至少 30 秒，避免大备份提交超时。`user_backups` 集合已存在，无需删除重建；集合应设为仅管理端可读写，客户端通过校验 OPENID 的云函数访问。
5. 在小程序中：我的 → 数据备份 → 重新检查 → 立即备份。确认云端时间和数量后，再用开发测试数据验证恢复。
