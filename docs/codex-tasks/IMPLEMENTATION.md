## 开发者工具与真机验收路径

1. 新建计划 → 动作库连续加 3 个动作 → 完成 → 保存并启用 → 查看教学打开详情。
2. 动作库首屏、向下分页、中文与英文多词搜索、部位和器械组合筛选、空结果清除筛选。
3. 今天 → 开始训练 → 完成一组 → ±15 秒 → 切后台 10 秒返回 → 结束振动并收起；长按选择默认时长。
4. 采用建议只填入未完成组；保存新成绩提示纪录，重复保存无重复提示；我的 → 统计查看个人纪录。
5. 已保存训练日后选择恢复日，打开内容正确；保存时取消替换仍保留原记录，确认后才替换。保存另一训练日后返回今天，应刷新到最新日。
6. 小屏设备、键盘弹出、长动作名、底部安全区和系统返回；确认主包小于 2MB。
