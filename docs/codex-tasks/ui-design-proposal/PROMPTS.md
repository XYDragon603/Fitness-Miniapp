# ImageGen 视觉稿提示词集

生成方式：内置 ImageGen。每个编号独立生成一张完整竖版微信小程序界面，参考同套视觉稿保持一致。历史日历、训练详情、统计、减脂习惯和体重趋势经定点修正后，保存的是修正版。

共享视觉要求：`Use case: ui-mockup`；直视角、完整手机视口、无设备外框；暖白 `#F5F3ED` 与深炭黑 `#141B1F`，荧光绿 `#C6F26A` 只强调主要操作和当前状态；大胆而清晰的中文字体、合理留白、细分隔线和足够大的触控目标；包含微信状态栏与胶囊；仅主 Tab 显示五项底栏；避免渐变、玻璃质感、重复浅色卡片、素材水印和无关营销文案。内容数字均为演示数据。

| 图片 | 单页内容要求 |
| --- | --- |
| 01 | 今天：日期、大标题、今日训练与开始按钮、七日节奏、下一动作。 |
| 02 | 动作库入口：搜索框、部位网格、浏览全部动作。 |
| 03 | 动作搜索：关键词、部位与器械筛选、结果列表、已选计数。 |
| 04 | 动作详情：名称、目标肌群、步骤、动作提示、加入计划。 |
| 05 | 计划总览：当前计划、训练日切换、动作清单、开始训练。 |
| 06 | 计划管理：当前启用计划、其他计划、启用与创建入口。 |
| 07 | 创建计划：计划名称、训练日、动作处方、添加动作/休息日、保存。 |
| 08 | 为训练日从动作库选动作：搜索筛选、选择状态、完成。 |
| 09 | 训练记录：当前动作、上次表现、重量次数输入、组完成状态。 |
| 10 | 组间计时：倒计时、±15 秒、跳过、60/90/120/180 秒预设。 |
| 11 | 加量建议：上次与本次对比、下次目标、采用建议、个人纪录。 |
| 12 | 恢复日：感受选择、休息打卡、备注、保存。 |
| 13 | 饮食首页：热量与三大营养、记录一餐、当日餐食。 |
| 14 | 添加方式：整道菜/精细拆分、拍照、相册、手动填写。 |
| 15 | 图片识别结果：食物与份量逐项确认、估算总计、修正与添加。 |
| 16 | 手动食物录入：名称、重量、热量、蛋白质、脂肪、碳水。 |
| 17 | 营养目标：身体资料、活动水平、目标、参考数字、保存。 |
| 18 | 我的：首页训练数字、本周图表、历史/统计/体重入口。 |
| 19 | 训练日历：2026 年 10 月，训练与休息标记，16 日以后不显示完成记录。 |
| 20 | 单日训练详情：3/3 完成、时长、训练量、3 个动作的组记录。 |
| 21 | 饮食历史：日期、总摄入、餐食分组与食物明细。 |
| 22 | 统计与个人纪录：累计、完成率、每周频次、最大重量与估算 1RM。 |
| 23 | 健康减脂：参考信息、非评判性的习惯勾选、本周节奏。 |
| 24 | 体重趋势：近 30 天变化、五点曲线、今日录入、最近记录。 |

动作器械插画、人体图、食物照片均为 ImageGen 生成的概念素材，未使用上游动作集的媒体文件。落地时须根据项目的真实数据与素材重新实现界面。
